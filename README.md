# 解殖民 · 展示与回收

东南亚解殖民艺术：**媒体优先滚动论文**（Vite + Vue 3）。论点——殖民权力的「展示」与「回收」。东亚／东北亚深挖交同学。

## Run

```bash
cd /workspace/decolonial-mvp
npm install
npm run dev
# production
npm run build
npm run preview -- --host 127.0.0.1 --port 4175
```

## Stack

- Vite + Vue 3 + TypeScript
- GSAP ScrollTrigger · Lenis · Howler · Sass
- Chinese UI · desktop ~1280 first
